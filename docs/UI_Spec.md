# UI Spec — ইউজার ইন্টারফেস স্পেসিফিকেশন

মোবাইল-ফার্স্ট, বাংলা/English দ্বিভাষিক, লাল-সাদা থিম। (ক্লাবের নিজস্ব রঙ থাকলে নিচের টোকেন বদলালেই হবে।)

---

## ১. ডিজাইন নীতি

1. **জরুরি কাজ আগে:** হোম পেজের প্রথম স্ক্রিনেই খোঁজার ফর্ম।
2. **এক হাতে ব্যবহারযোগ্য:** বড় ট্যাপ এরিয়া (সর্বনিম্ন ৪৪px), মূল বাটন নিচের দিকে।
3. **স্পষ্ট স্ট্যাটাস:** রঙ + আইকন + টেক্সট একসাথে (শুধু রঙে নির্ভর নয়)।
4. **কম টাইপিং:** ড্রপডাউন, টগল, ডেট পিকার।
5. **দুই ভাষায় সমান সুন্দর:** বাংলা ও English টেক্সটের দৈর্ঘ্য আলাদা, তাই ফিক্সড-উইডথ বাটন এড়ানো।

## ৩. কম্পোনেন্ট লাইব্রেরি

### বাটন
- **Primary:** লাল ব্যাকগ্রাউন্ড, সাদা টেক্সট
- **Secondary:** সাদা ব্যাকগ্রাউন্ড, লাল বর্ডার ও টেক্সট
- **Ghost:** শুধু টেক্সট
- **Danger:** গাঢ় লাল, ডিলিট/রিজেক্টের জন্য
- অবস্থা: default, hover, focus (স্পষ্ট আউটলাইন), disabled, loading (স্পিনার)

### ইনপুট ফিল্ড
- উপরে লেবেল, নিচে সাহায্যকারী টেক্সট/ত্রুটি (লাল, আইকনসহ)
- ফোন ফিল্ডে `inputmode="tel"`, `pattern="01[3-9][0-9]{8}"`
- ডেট ফিল্ডে `type="date"`, জন্ম তারিখে সর্বোচ্চ = আজ থেকে ১৮ বছর আগে

### রক্তের গ্রুপ চিপ সিলেক্টর
`A+  A-  B+  B-  AB+  AB-  O+  O-` — ৮টি চিপ, ৪×২ গ্রিড (মোবাইলে), একটি বাছাই করা যায়। বাছাই করা চিপ লাল ব্যাকগ্রাউন্ড।

### স্ট্যাটাস ব্যাজ
| ব্যাজ | বাংলা | English |
|--------|--------|---------|
| 🟢 সবুজ পিল | Available | Available |
| 🟡 হলুদ পিল | আর ১৫ দিন পর পারবেন | Available in 15 days |
| ⚪ ধূসর পিল (অ্যাডমিন/প্রোফাইলে) | এখন available নন | Not available |
| 🟠 অ্যাডমিন: Pending | অনুমোদনের অপেক্ষায় | Pending |
| 🔴 অ্যাডমিন: Rejected/Suspended | প্রত্যাখ্যাত / সাসপেন্ড | Rejected / Suspended |

### ডোনার কার্ড

```
┌──────────────────────────────────┐
│ [ছবি]  রহিম উদ্দিন        [ B+ ]  │
│  ৩২ বছর · পুরুষ                  │
│  📍 ধামরাই, ঢাকা                 │
│  শেষ রক্তদান: ১২ জুন ২০২৬        │
│  [🟢 Available]                  │
│  [ 📞 কল করুন  01712-XXXXXX ]    │
└──────────────────────────────────┘
```

**🟡 অবস্থায়:**
```
│  [🟡 আর ১৫ দিন পর পারবেন]        │
│  [ নম্বর লুকানো ]  (বাটন নেই)    │
```

- রক্তের গ্রুপ বড় লাল ব্যাজে (কার্ডের ডান-উপরে)।
- ঠিকানা: ইউনিয়ন, উপজেলা, জেলা (ভাষা অনুযায়ী)।
- গ্রামের নাম ছোট টেক্সটে।
- ছবি না থাকলে নামের আদ্যক্ষর বা ডিফল্ট অবতার।

### টগল সুইচ
- বড় (ন্যূনতম ৪৪px উচ্চতা), লেবেল পাশে, অবস্থা টেক্সটেও লেখা ("চালু/বন্ধ")।
- "আমি এখন available নই" টগল: কনফার্মেশন ছাড়াই সাথে সাথে সেভ হবে (AJAX), সফল হলে ছোট টোস্ট।

### টোস্ট/অ্যালার্ট
- সফল (সবুজ), ত্রুটি (লাল), তথ্য (নীল/ধূসর); ৪ সেকেন্ড পর অদৃশ্য; `role="status"`।

### মডাল (কনফার্মেশন)
- ডিলিট, Reject, Suspend-এর জন্য; কারণ ও মেয়াদ ফিল্ডসহ; Esc দিয়ে বন্ধ।

### স্কেলিটন/লোডিং
- সার্চ চলাকালীন ৩টি কার্ড-আকৃতির স্কেলিটন।

## ৪. পেজভিত্তিক স্পেসিফিকেশন

### ৪.১ হোম / ডোনার খোঁজা (`/`)

**মোবাইল লেআউট (উপর থেকে নিচে):**
1. **হেডার:** লোগো/সংগঠনের নাম · 🌐 ভাষা · মেনু (হ্যামবার্গার)
2. **হিরো:** শিরোনাম "রক্ত দরকার? এখনই খুঁজুন", ছোট সাবটাইটেল
3. **ফিল্টার কার্ড:**
   - রক্তের গ্রুপ চিপ (বাধ্যতামূলক)
   - বিভাগ ▾ → জেলা ▾ → (সিটি কর্পোরেশন ▾ **অথবা** উপজেলা ▾ → ইউনিয়ন/পৌরসভা ▾)
   - জেলা বাছার পর সিটি কর্পোরেশন থাকলে সেটি শহরের ঠিকানার বিকল্প পথ হিসেবে দেখাবে; একটি ডোনারের ঠিকানায় সিটি কর্পোরেশন ও উপজেলা/ইউনিয়ন একসঙ্গে বাছা যাবে না
   - টগল: "শুধু Available দেখান" (ডিফল্ট ON)
   - বাটন: **খুঁজুন** (ফুল-উইডথ, প্রাইমারি)
4. **রেজাল্ট এরিয়া:** "১২ জন ডোনার পাওয়া গেছে" + কার্ড লিস্ট
5. **পেজিনেশন:** আগের/পরের + পেজ নম্বর
6. **ফুটার:** সংগঠনের যোগাযোগ, ডিসক্লেইমার ("তথ্য ডোনারের দেওয়া; রক্তদানের আগে চিকিৎসা-যোগ্যতা নিজে নিশ্চিত করুন"), ভাষা সুইচ

**ডেস্কটপ:** ফিল্টার বাঁদিকে স্টিকি সাইডবার (৩০০px), ডানে ৩ কলাম কার্ড।

**খালি অবস্থা:** ছবি/আইকন + "কোনো ডোনার পাওয়া যায়নি। 'শুধু Available' বন্ধ করে বা এলাকা বড় করে দেখুন।"

### ৪.২ রেজিস্ট্রেশন (`/register.php`)

সেকশনসহ একটানা ফর্ম (মোবাইলে ধাপে ধাপে ৩ স্টেপ ভাবা যায়):

**ধাপ ১ — অ্যাকাউন্ট:** মোবাইল নম্বর, পাসওয়ার্ড, পাসওয়ার্ড নিশ্চিত করুন
**ধাপ ২ — ব্যক্তিগত:** নাম, ছবি আপলোড (প্রিভিউসহ), জন্ম তারিখ, লিঙ্গ (রেডিও), রক্তের গ্রুপ (চিপ)
**ধাপ ৩ — ঠিকানা:** বিভাগ → জেলা → (সিটি কর্পোরেশন অথবা উপজেলা → ইউনিয়ন/পৌরসভা) (ড্রপডাউন), গ্রাম/এলাকা (টেক্সট), শেষ রক্তদানের তারিখ (ঐচ্ছিক)

- ডিসক্লেইমার চেকবক্স: "আমি স্বেচ্ছায় রক্তদানে আগ্রহী এবং আমার দেওয়া তথ্য সঠিক"
- সাবমিটের পর: Auto মোডে "রেজিস্ট্রেশন সম্পন্ন" + লগইন বাটন; Manual মোডে "অ্যাডমিন অনুমোদনের পর আপনি তালিকায় আসবেন"
- ইনলাইন ভ্যালিডেশন (ফোকাস হারানোর পর) + সাবমিটে সার্ভার ভ্যালিডেশন

### ৪.৩ লগইন (`/login.php`)
- মোবাইল, পাসওয়ার্ড (চোখ আইকন দিয়ে দেখা), "লগইন" বাটন
- "পাসওয়ার্ড ভুলে গেছেন?" → বার্তা: "অ্যাডমিনের সাথে যোগাযোগ করুন" + সংগঠনের ফোন নম্বর
- অবস্থা অনুযায়ী বার্তা: pending, rejected, লক

### ৪.৪ ইউজার ড্যাশবোর্ড (`/user/dashboard.php`)
- অভিবাদন: "আসসালামু আলাইকুম, রহিম"
- **স্ট্যাটাস কার্ড (বড়):**
  - 🟢 "আপনি এখন রক্ত দিতে পারবেন" অথবা 🟡 "আপনি আর ২৩ দিন পর রক্ত দিতে পারবেন" (প্রগ্রেস বার: ১২০ দিনের কতটা পূর্ণ)
  - **টগল:** "আমি এখন available নই" (OFF হলে ধূসর কার্ড ও "আপনি সার্চ তালিকায় নেই" বার্তা)
- **অ্যাকাউন্ট অবস্থা:** pending হলে হলুদ ব্যানার; সাসপেন্ড হলে লাল ব্যানার (মেয়াদ ও কারণসহ)
- কুইক অ্যাকশন: "রক্তদান যোগ করুন", "প্রোফাইল এডিট"
- শেষ ৩টি রক্তদান (সংক্ষিপ্ত)
- মোট রক্তদানের সংখ্যা

### ৪.৫ প্রোফাইল / User Details (`/user/profile.php`)
- উপরে ছবি (বদলানোর বাটন), নাম
- ফিল্ড তালিকা: নাম, মোবাইল, রক্তের গ্রুপ, বয়স (জন্ম তারিখ থেকে), লিঙ্গ, ঠিকানা (বিভাগ→ইউনিয়ন, গ্রাম)
- "এডিট" মোডে সব ফিল্ড ইনপুট হয়; **রক্তের গ্রুপ ও মোবাইল নম্বর** বদলাতে চাইলে নোট: "পরিবর্তনের জন্য অ্যাডমিনের অনুমোদন লাগবে"
- সেভ ও বাতিল বাটন

### ৪.৬ হিস্টরি (`/user/history.php`)
- উপরে: "রক্তদান যোগ করুন" বাটন
- টেবিল/কার্ড লিস্ট (নতুন থেকে পুরনো): তারিখ, স্থান, নোট, মুছুন
- যোগ করার ফর্ম (মডাল): তারিখ (≤ আজ), স্থান/হাসপাতাল, নোট
- খালি অবস্থা: "এখনও কোনো রক্তদান যোগ করা হয়নি"

### ৪.৭ অ্যাডমিন লগইন (`/admin/login.php`)
- ইউজারনেম, পাসওয়ার্ড; সাধারণ সাইটের থেকে আলাদা সরল ডিজাইন

### ৪.৮ অ্যাডমিন ড্যাশবোর্ড
- **স্ট্যাট কার্ড:** মোট ডোনার · অনুমোদনের অপেক্ষায় (ক্লিক করলে Pending পেজ) · এখন Available · সাসপেন্ড
- **রক্তের গ্রুপ অনুযায়ী বার চার্ট** (৮টি বার; সবচেয়ে কম গ্রুপ হাইলাইট করা যায়)
- **সাম্প্রতিক রেজিস্ট্রেশন** (শেষ ১০টি)
- ডেস্কটপে বাঁদিকে সাইডবার; মোবাইলে টপ-বার + ড্রয়ার

### ৪.৯ অ্যাডমিন: ডোনার তালিকা (`/admin/users.php`)
- ফিল্টার বার: সার্চ (নাম/নম্বর), স্ট্যাটাস, রক্তের গ্রুপ, বিভাগ→উপজেলা
- টেবিল কলাম: ছবি, নাম, নম্বর, গ্রুপ, এলাকা, স্ট্যাটাস ব্যাজ, শেষ রক্তদান, অ্যাকশন
- অ্যাকশন (⋮ মেনু): দেখুন, এডিট, Approve, Reject, Suspend/Unsuspend, পাসওয়ার্ড রিসেট, মুছুন
- মোবাইলে টেবিল কার্ড লিস্টে রূপান্তরিত
- বর্তমান ফিল্টারসহ পুরো ডোনার তালিকা UTF-8 CSV হিসেবে ডাউনলোড করা যাবে

### ৪.১০ অ্যাডমিন: ডোনার যুক্ত করুন
- রেজিস্ট্রেশন ফর্মের মতোই, অতিরিক্ত ফিল্ড: **অস্থায়ী পাসওয়ার্ড** (অটো-জেনারেট বাটন, কপি বাটন) ও "জানানোর জন্য কপি করুন" সারাংশ
- সাবমিটের পর নিশ্চিতকরণ স্ক্রিন: নম্বর + অস্থায়ী পাসওয়ার্ড (একবারই দেখানো হবে)

### ৪.১১ অ্যাডমিন: Pending
- কার্ড/টেবিল লিস্ট; প্রতি সারিতে বিস্তারিত দেখা + দ্রুত Approve ✔ / Reject ✖
- Reject-এ কারণ লেখার মডাল
- বাল্ক সিলেক্ট ও "নির্বাচিত সব Approve" (ঐচ্ছিক)
